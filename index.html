Chemical data infrastructure

Public repository

NiAsymCoupling

Explore the repository ↗

A literature-derived reaction database connecting molecular structures, conditions, selectivity, and source evidence for nickel asymmetric coupling.

I curated source-linked reaction records and developed SQLite and CSV exports with explicit missing values and quality flags, alongside query examples and validation tools.

7,935Literature-derived result rows
4,596Main-scope result rows

Counts refer to the v2.0.0 public derivative and describe source-result rows, not independent experiments. Main scope: nickel-reported C(sp²)–C(sp³) bond formation.

Data scope & responsible use

Source locators, incomplete structures, missing values, and potential duplicates remain explicit. Consult the repository for provenance, licensing, and known limitations before selecting records or evaluating models.
